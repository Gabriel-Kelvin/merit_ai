# Merit AI Candidate Experience

The React and TypeScript candidate application for Merit AI. It guides a candidate from project context through an adaptive assessment and into an evidence-backed readiness report.

## Run locally

```powershell
npm install
npm run dev
```

The development server expects the assessment API at `http://127.0.0.1:8000` by default. Copy `.env.example` to `.env.local` to use a different backend URL.

## Quality checks

```powershell
npm run lint
npm run build
```
